# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue containing:

- real player account names or passwords;
- unused or private serial codes;
- screenshots containing sensitive data; or
- step-by-step details of an unpatched vulnerability.

Report security concerns privately through the contact page:

https://hktr.uk/contact-us

Please include the extension version, Chrome version, a concise description,
and reproduction steps using dummy data only. We will review reports as time
allows. This community project does not currently operate a paid bug-bounty
programme.

## Supported versions

Security fixes are provided for the latest version available from the Chrome
Web Store. Development code may be ahead of the published Store version.
